# HedraAiKnowledge (HAK) - The External Cortex of Hedra

## 🧠 المشروع والهدف الأساسي
**HedraAiKnowledge (HAK)** ليس مجرد تطبيق، بل هو امتداد رقمي لـ "الدماغ الخارجي" الخاص بـ **هدرا**. الهدف هو بناء مكتبة شاملة وذكية تجمع المعلومات الشخصية، التقنية، الحساسة، والمحادثات من مختلف المصادر (واتساب، فيسبوك، ماسنجر) وتحويلها إلى شبكة معرفية مترابطة يمكن استجوابها عبر الذكاء الاصطناعي.

### ملكية المشروع
- **المؤلف والمالك**: هدرا (Hedra).
- **الاستخدام**: أداة شخصية احترافية لجمع وإدارة المعرفة.

## 🚀 المميزات والقدرات (Features)

### 1. الإدخال والاستيراد (Mass Ingestion)
- **Mass Data Import**: استيراد سجلات المحادثات (XML, JSON, Text) وتقسيمها لنقاط معرفية.
- **Web Scraper Agent**: وكيل متخصص يسحب محتوى المقالات والروابط ويحولها لـ Markdown ثم يخزنها.
- **Manual Smart Editor**: محرر للتدوين اليدوي مع ميزة التصنيف الآلي.
- **Background Jobs**: نظام معالجة خلفي للملفات الضخمة (100MB+) لضمان عدم توقف العملية من خلال تتبع الـ `ProcessingTasks`.

### 2. الدماغ الرقمي والبحث الهجين
- **Neural Graph**: تمثيل مرئي (Force Graph) للعلاقات بين المعلومات.
- **Hybrid Search**: دمج البحث التقليدي (MySQL) مع البحث الدلالي (Pinecone Vector DB) للرد على أسئلة معقدة.
- **RAG System**: نظام توليد الإجابات المدعم بالاسترجاع (Retrieval-Augmented Generation).

### 3. وكلاء الذكاء الاصطناعي (AI Swarm)
- **The Boss Agent**: المحرك الرئيسي لاتخاذ القرارات والرد النهائي.
- **Summarizer Agent**: وكيل لتلخيص النصوص الطويلة.
- **Task Extractor Agent**: وكيل لاستخراج المهام والوعود من المحادثات.
- **Psychology Agent**: وكيل لتحليل الشخصيات والأنماط من خلال أسلوب المحادثة.

### 4. الأمان والتنظيم
- **Secure Vault**: خزنة مشفرة بـ AES-256-CBC لتخزين كلمات المرور والمفاتيح الحساسة.
- **Registry & Settings**: إدارة كاملة للـ Tags، الألوان، الأيقونات، ومفاتيح الـ API.
- **Log System**: تتبع كامل لكل تفصيلة وعملية يقوم بها النظام في صفحة `/logs`.

## 📂 شرح ملفات التوثيق (Documentation)

- `API_DOCS.md`: توثيق جميع الـ Endpoints لاستخدامها في تطبيقات خارجية (الـ API الخاص بـ هدرا).
- `ARCHITECTURE.md`: شرح الهيكل الفني (Stack، Schema، Data Flow).

## 🛠 طرق تشغيل المشروع
1. **تثبيت الاعتمادات**: `npm install`
2. **إعداد البيئة**: ملء ملف `.env` بمفاتيح Gemini و Pinecone و MySQL.
3. **تحديث القاعدة**: `npx prisma db push`
4. **توليد الكلاينت**: `npx prisma generate`
5. **التشغيل**: `npm run dev`
